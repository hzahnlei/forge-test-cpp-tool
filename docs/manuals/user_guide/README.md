# User's Guide

The user's guide is written for those who use this artifact: the users of an application, the
developers who call a library, whoever assembles and connects a circuit board. It follows
[Diátaxis](https://diataxis.fr): four kinds of documentation, each for one need of the reader.
Keep each document in the section of its kind.

This file is written by `repo update`; write the guide in other files of this directory.

## Template

```markdown
# User's Guide: Artifact Name

## Getting Started

A tutorial: one complete, working first use, step by step, for a newcomer.

## How-to Guides

One guide per task a user wants to get done, such as importing data or replacing a part.

## Reference

The facts to look up: commands, options, settings, messages, pin assignments.

## Background

Explanations of concepts and decisions that help the user understand the artifact.
```
